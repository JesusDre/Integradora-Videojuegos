# Licencias de assets externos

Todo asset que no hicimos nosotros se anota aquí (o en la hoja compartida del equipo) en el mismo momento en que se descarga.

Notas:
- Preferir CC0. CC-BY exige crédito: anotarlo para la pantalla de créditos.
- Modelos generados con IA (Meshy, Tripo, `generate_3d`): anotar la herramienta, el plan usado y sus términos; revisarlos antes, porque en planes gratis pueden pedir atribución o dejar el modelo público.
- Mixamo: anotar personaje y animaciones usadas.
- Si no se puede comprobar la licencia, no se usa.
